I'm an embedded Linux and robotics software engineer from China 🇨🇳, with more than 10 years of experience building software for robots, intelligent devices, and connected systems.

My engineering journey spans:

**Hardware → Industrial Robotics → Telecommunications → IoT → Electric Vehicles → Indie Hacker → Robotics**

I focus on **embedded Linux**, **robotics**, and **AIoT**, while also exploring how open source, STEM education, and technology can contribute to the **Sustainable Development Goals (SDGs)**.

### What I'm working on

* 🔥 Building [OpenEmber](https://github.com/openember/openember), a modular C/C++ runtime framework for robots and intelligent devices.
* 📚 Maintaining [GetIoT.tech](https://getiot.tech/), an open engineering knowledge base for embedded Linux, IoT, and robotics.
* 🛠️ Creating practical developer tools, Python packages, web utilities, and embedded hardware projects.
* 🌱 Exploring technology for sustainability, environmental protection, and social good.

### Open-source contributions

I have contributed code to [Linux](https://github.com/torvalds/linux), [RT-Thread](https://github.com/RT-Thread/rt-thread), [LVGL](https://github.com/lvgl/lvgl), [openEuler](https://gitee.com/openeuler), [ShokaX](https://github.com/theme-shoka-x), and other open-source projects.

I believe in open source, lifelong learning, and freedom. ❤️
